# Paired fixed-budget solver experiment

The pilot used a held-out unweighted cycle of length 60, seed 17, and 4,096 point evaluations per solver. Its timing record is in pilot/timing.json. We used elapsed time to size the protocol and did not tune for a winning formulation. The following design was fixed before any main-series solver runs.

Run PROTES 0.3.12 and TTOpt 0.6.2 on the four fixed Max-Cut instances and three mixed-sign polynomial instances listed in MODEL_INPUTS.md. Compare quadratic and XOR cubic forms for each graph. Compare original HUBO, sign-dependent and local symmetric Rosenberg forms for each polynomial. Use a common circuit and gap of one for both lifts. Every comparison preserves the natural original objective under decoding or minimization over the auxiliaries. The preflight checks the mixed and triangle values against the B2 fixtures, verifies the independent star counterexample, exhausts the small original instances and checks the independent evaluator on large instances.

Run eight independent initializations per combination, seeds 201 through 208, paired by seed across formulations within the same instance and solver. Each run has exactly 4,096 objective-point evaluations. Treat duplicate points as new queries, including duplicates within a batch. No cache, tuning, optimum-based stop or restart during a run. The 272 jobs are shuffled once by Python Random(11023). The 120-second per-run timeout and all execution errors are recorded. Incomplete runs are excluded from fixed-budget comparisons. A recorded failure can be retried explicitly with its initial record preserved. A resumed process skips matching completed run IDs. Only one process owns each output directory.

PROTES uses binary modes, internal rank 3, 64 samples per batch, 8 elites, one Adam step with learning rate 0.05, default random initialization from the solver seed, and minimization. The budget is exactly divisible by the sample count. TTOpt uses binary indices, maximal rank 4, exponential smoothing factor 1.0, random initial TT cores from the solver seed, deterministic sweeps thereafter, the default inner optimum inclusion, and no random augmentation. Its native wrapper truncates the final batch to the remaining budget. Actual and proposed batch sizes are logged. For both solvers the loss is minus the cut weight or the signed polynomial/lift energy.

Each native returned candidate minimizes solver loss among evaluated points. Separately, record the best natural score of any queried original assignment after decoding, even if its auxiliaries are inconsistent. The first such assignment wins ties. Also record the feasibility, returned natural score, lifted loss and all encoded bitstrings. Reconstruct the original-score best-so-far trajectory in query order after the solver returns. Scoring for analysis does not feed back into the algorithm. Offline scoring, data loading and I/O are excluded from timings. Wall time covers the solver call and evaluation logging, including JAX compilation when incurred. Calls run sequentially in a shared process and can reuse backend caches.

The primary quantity is the within-seed difference in best decoded score at budget, oriented so that positive favors the alternative. Report all seed differences and descriptive medians, quartiles, extremes and ties separately for every case and solver. Also give score and time distributions, optimal hits, native candidate feasibility and natural scores. Repeated starts estimate seed variability on these fixed cases. No pooled independent-graph inference or uniform solver ranking is planned. The exact optimum source for each case is in the input manifest.

On the five-bit shared mixed control, vary the load margin over 0, 1/4, 1, 4, 16, and include half-load zero-margin controls. For each policy use unrounded coefficients and 3-, 5-, 8-bit symmetric full-scale quantization of the collected coefficients with ties to even. Compare each post-rounding fiber minimum with the unrounded original in natural units, and compare optimal decoded sets.

Measured platform: Apple M5 MacBook Pro (10 CPU cores, 16 GB), macOS arm64, CPython 3.9.6. Single benchmark process, CPU JAX, default float32 solver internals, exact integer objective evaluator. NumPy, Accelerate and BLAS thread limit environment variables are set to one in engines.py. JAX/XLA uses its CPU runtime. Seed, backend, software versions and raw objective points accompany the result. The smoke profile uses seed 200 and 128 evaluations on the triangle and shared mixed control.
